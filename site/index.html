Small on purpose

It does one thing: when you press it, your computer hears a MIDI message. Which message is up to you.

Plug and play

It shows up as a standard USB MIDI device called “MIDI Button” on Windows, macOS, Linux, iPad and Android. Nothing to install.

Set up in the browser

Open the configurator in Chrome or Edge, click Connect, pick your message. Changes apply instantly; save them and they stay on the button.

Note, CC or program

Any note with any velocity, any controller with press and release values, or a program change. Momentary or toggle, on any of the 16 channels.

Build one in an evening

Two solder joints and a file copy. If you can strip a wire you can build this.

1

Get the parts

  • Waveshare RP2350-Zero or a Raspberry Pi Pico 2
  • Any momentary switch footswitch, arcade button, tactile switch
  • Two wires and a soldering iron
  • A USB-C data cable not a charge-only one
2

Wire the switch

Solder one leg of the switch to GP9 and the other to GP13. Either way round works: the firmware uses GP9 as the return, so you don’t need a ground wire.

On the RP2350-Zero both are pads on the edge opposite the USB port. On a Pico 2 they’re pins 12 (GP9) and 17 (GP13). No switch yet? The board’s BOOT button works too.

3

Load the firmware

Hold the board’s BOOT button while you plug it in. A drive called RP2350 appears. Drag the file for your board onto it and it restarts as a MIDI Button.

RP2350-Zero firmware Pico 2 firmware

Built automatically from the latest source.

4

Pick what it sends

Open the configurator, click Connect, choose a note, CC or program change and hit Save. The LED on the RP2350-Zero shows the type: blue for notes, green for CCs, amber for program changes.

Questions

Which browsers can configure it?

Chrome, Edge and other Chromium browsers on desktop and Android. Firefox works after it asks to install a small permission add-on. Safari and iOS don’t support Web MIDI, so they can’t configure it, but the button itself works fine on a Mac or iPad once it’s set up.

Does it need a driver or an app?

No. It’s a class-compliant USB MIDI device, the same kind as most keyboards and controllers. Your settings are stored on the button, so you only need the configurator when you want to change them.

The configurator says “No MIDI Button found”.

Check the cable carries data (plenty only charge), make sure the firmware is loaded (the board should show up as “MIDI Button”), and close any music app that might be holding the MIDI port open, then try again.

Can I use different pins, or more buttons?

Yes, with a small code change. The pins are at the top of the sketch. More buttons would need the settings and the configurator extended; pull requests welcome.

What’s the difference between momentary and toggle?

Momentary sends “on” when you press and “off” when you let go, like a sustain pedal. Toggle sends “on” the first time you press and “off” the next, so you don’t have to hold it down.

How do I build the firmware myself?

It’s a single Arduino sketch for the Raspberry Pi Pico / RP2350 core by Earle Philhower. The README on GitHub has the steps, the wiring and the SysEx protocol the configurator speaks.
